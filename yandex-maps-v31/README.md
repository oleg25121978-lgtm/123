# Яндекс Карты 31.1.5 → Rokid HUD
Отдельный режим разработки. **Не менять рабочий TEST9 с Яндекс Навигатором.**

## Цель
- Huawei Mate X3: обычные Яндекс Карты, построение маршрута и штатное ведение.
- Rokid Glasses: только нижний минималистичный HUD, без зеркалирования карты.
- Настоящие значения из работающего маршрута: скорость, ограничение, стрелка/дистанция до поворота, полосы, рассчитанное Яндексом ETA, геометрия мини-карты.
- Системные показатели очков получать с очков.

## Исходная версия
Проверенная последняя стабильная версия на 23.11.2026 — **31.1.5**, versionCode **739740290**, package **ru.yandex.yandexmaps**. APKMirror публикует её в формате split bundle (base + 3 splits). Оригинал этой версии не хранится в репозитории и в текущем окружении ещё не исследован.
Имеющийся более старый APK **10.5.1** используется **только для проверки анализатора**, а не для выдачи его за версию 31.1.5.

## Подтверждено документацией
В NaviKit/MapKit разработчикам доступны `Navigation.getGuidance`, `Guidance.getWindshield`, `Guidance.getManoeuvres`, `Guidance.getLaneSigns`, `Guidance.getLocation`, `Guidance.getSpeedLimit`, а также `GuidanceListener`. **Это не значит, что внутренний объект приложения Яндекс Карт доступен внешнему приложению!** Необходимо исследовать настоящий APK v31.

## Этапы
1. Скачать из проверенного источника и проверить **оригинальный** пакет 31.1.5 вместе со split APK.
2. Запустить `inspect_maps_apk.py`, затем проверить реальные вызовы и жизненный цикл навигации; наличие строк **не доказывает** их использование.
3. Только после подтверждения точек подключения — встроить **read-only** модуль. Не создавать вторую сессию ведения и не менять маршрутизацию Яндекса.
4. Добавить независимый от Test9 режим передачи на Rokid. Реальный ETA берём у Яндекса; при отсутствии источника передаём `null`.
5. Испытать запуск/первичную настройку, сворачивание, звонки, камеру, переподключение и подпись на Mate X3 и Rokid.

**Статус:** отдельная ветка и контракт HUD подготовлены. Готовый модифицированный APK 31.1.5 **пока не создан**.
